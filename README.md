# Redux Toolkit Fundamentals

A beginner-friendly Redux Toolkit practice project built with React.

## Features

- Counter App
- Increment Counter
- Todo App
- Add Todo
- Edit Todo
- Delete Todo
- Redux Store
- Redux Slice
- Reducers
- Payload
- useSelector
- useDispatch

## Concepts Covered

- createSlice()
- configureStore()
- Provider
- useSelector()
- useDispatch()
- Payload Handling
- State Management
- CRUD Operations using Redux Toolkit

## Tech Stack

- React
- Redux Toolkit
- React Redux
- JavaScript
- Vite

## Learning Outcome

This project was created to understand the fundamentals of Redux Toolkit, including global state management, reducers, actions, payloads, and practical implementation through Counter and Todo applications.
